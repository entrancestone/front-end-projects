# front-end-projects

A small photo gallery side project that shows off some photos I like.

## What's in the repo

`photo gallery project.html` is the gallery page, and `gallery.css` holds its styling. It is plain HTML and CSS with no build step or dependencies.

## Running it

Download or clone the repo and open `photo gallery project.html` in any web browser. Keep `gallery.css` in the same folder so the styles load.

## Notes

This is an early front-end practice project from 2019.
